# Demonstracao

- `samples/`: entradas pequenas, autorizadas e adequadas para reproducao.
- `evidence/`: capturas ou resultados finais selecionados para apoiar a apresentacao.

O passo a passo oficial da demonstracao fica em `docs/entrega/roteiro-demo.md`. Nao armazene
material sensivel nem apresente uma evidencia gravada como se fosse execucao ao vivo.
